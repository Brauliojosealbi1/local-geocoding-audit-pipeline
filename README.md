# Local Geocoding & Geospatial Quality Audit Engine

Pipeline integral y reproducible de ingeniería de datos para la auditoría y reconciliación de coordenadas geográficas y direcciones a escala masiva. La solución desacopla la infraestructura analítica mediante un clúster contenedorizado local (Nominatim 4.4 + PostGIS) optimizado para búsquedas espaciales multidimensionales de alta velocidad. Implementa en R un cliente multi-hilo asíncrono (curl::multi_run) con aislamiento léxico de variables, junto a un motor de normalización canónica que combina el cálculo de solapamiento de tokens (Token Overlap Ratio), métricas de similitud difusa (Jaro-Winkler) y validación cruzada jerárquica político-administrativa. Diseñado para mitigar restricciones de tasa (rate-limiting), costos recurrentes de API y contingencias de privacidad de datos en entornos analíticos de alta exigencia.

An end-to-end, reproducible data engineering pipeline designed for large-scale spatial auditing, coordinate validation, and address reconciliation. The architecture containerizes an on-premise Nominatim 4.4 and PostGIS cluster via Docker Compose, performance-tuned for dense multidimensional spatial indexing. It features a high-throughput asynchronous R client utilizing non-blocking connection pools (curl::multi_run) with lexical scoping resolution, alongside a robust data-cleaning engine. The evaluation framework combines canonical string sanitation, Token Overlap Ratio scoring, Jaro-Winkler string distances, and administrative boundary cross-validation. Built to eliminate rate-limiting bottlenecks, recurring cloud geocoding fees, and external data exposure in data governance workflows.

## Architecture
- **Infrastructure:** Docker Compose (Nominatim 4.4 + PostgreSQL/PostGIS) with memory tuning for dense GiST indexing.
- **Client Pipeline (R):** Asynchronous multi-thread HTTP worker pool (`curl::multi_run`) with lexical scoping isolation.
- **Data Quality Logic:** Canonical string normalization, token-overlap scoring, and Jaro-Winkler distance against official administrative boundaries.
